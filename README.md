# Luminara releases

Signed and notarized builds of Luminara, a native macOS app that turns ebooks
(EPUB, PDF, plain text) into audiobooks with local text-to-speech models.

This repository holds releases only. The app's update check reads it.

## Download

Get the latest DMG from [Releases](https://github.com/caemlyn/Luminara-releases/releases/latest).

## Requirements

- macOS 14 (Sonoma) or later
- A Mac with Apple Silicon
- Python 3.10 to 3.12 (Homebrew); the app sets up its own environment on first run

## Install

1. Download the DMG and open it.
2. Drag Luminara to Applications.
3. Open Luminara from Applications.

## Problems

Open an [issue](https://github.com/caemlyn/Luminara-releases/issues/new).
