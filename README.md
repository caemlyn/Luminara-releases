## What it does

- **Reads EPUB, PDF and plain text**, finds the chapters, and turns each one into narrated audio.
- **Speech is made on your Mac.** It is generated by local models on Apple Silicon (MLX on the
  Metal GPU). After the first download of a model, conversion works offline, with no account,
  subscription or per-word fees.
- **15 voice models to choose from**, from a 217 MB model that runs on any Apple Silicon Mac to
  Drama 3 for Macs with 96 GB of memory. See [Voice models](#voice-models).
- **A cast of voices.** Luminara can find the characters in a book and give each one its own voice.
  Casts can be saved and reused across a series. Character detection uses a language model you
  choose. See [Language models](#language-models).
- **Expressive reading** on the models that support it.
- **Your own voices.** Add a short recording, and the models that copy a voice can read in it.
- **Real audiobook files**: M4B with chapter markers, MP3, MP4 or WAV. Send a finished book to
  Apple Books or Music, or write chapter and metadata sidecar files for other players.
- **Built for long books.** Conversions run in a queue. A stopped or failed conversion keeps its
  finished chapters and can be continued later. Single chapters or single lines can be re-recorded.
- **Listen in the app**, with a sleep timer, bookmarks, media keys and a transcript that follows along.
- **Library, series and pronunciation lists** to keep books organized and names read correctly.
- **Automation**: a watch folder that converts new files, and Shortcuts actions.
- **Web novels**: an optional add-on downloads web novels to convert. See [Web novels](#web-novels).
- **Audio tools**: an audio check that listens to the finished book, and noise cleanup. See
  [Audio tools](#audio-tools).
- **Update check**: the app looks here for new releases and tells you when one is out.

## Requirements

| | |
|---|---|
| macOS | 14 (Sonoma) or later |
| Mac | Apple Silicon (M1 or later). Intel Macs are not supported. |
| Memory | Larger models need more. Drama 3 (4-bit) needs 32 GB; Drama 3 needs 96 GB. |
| Python | Python 3.10, 3.11 or 3.12, from [Homebrew](https://brew.sh): `brew install python@3.12` |
| ffmpeg | From Homebrew: `brew install ffmpeg` |
| Disk | Room for the voice models you install (several GB each for most) and your audiobooks |

Python and ffmpeg are not included in the app. On first launch, Luminara creates its own Python
environment and installs what the voice models need into it. The **Tools** page in Settings
shows what is installed.

## Install

1. Download the `.dmg` file from the [latest release](https://github.com/caemlyn/Luminara-releases/releases/latest).
2. Open it and drag **Luminara** to **Applications**.
3. Open Luminara from Applications. Releases are signed and notarized by Apple, so macOS opens them
   without warnings.
4. Install a voice model on the **Voice Models** page, then drop a book on **Convert**.

Each release lists a SHA-256 checksum in `checksums.txt`. To check a download:

```bash
shasum -a 256 -c checksums.txt
```

## Updating

Luminara checks this repository for new releases daily or weekly, or only when you ask (Settings). To update, download the new DMG and replace the app in Applications. Your library,
voices, models and settings are kept.

## Language models

A language model (LLM) is optional. Without one, Luminara reads the whole book in one voice. With
one, it can:

- **find the characters** in a book and suggest a voice for each, for a full cast,
- **mark emotions** in the text, for the voice models that read with emotion,
- **write delivery directions** for each chapter (off by default; turn it on in **Settings >
  Language Model**),
- **clean up web novel chapters** (see [Web novels](#web-novels)).

Choose the provider in **Settings > Language Model**:

| Provider | Where it runs | What you need | License or terms |
|---|---|---|---|
| [LM Studio](https://lmstudio.ai) | On your Mac | LM Studio running with a model loaded. Pick the model from the list in Settings. | The model's own license ([preferred models](model-licenses/README.md#language-models)) |
| [Ollama](https://ollama.com) | On your Mac | Ollama running with a model pulled. Pick the model from the list in Settings. | The model's own license |
| Anthropic | Cloud | An API key. Default model `claude-opus-4-6`. | [Commercial Terms of Service](https://www.anthropic.com/legal/commercial-terms) |
| OpenAI | Cloud | An API key. Default model `gpt-4o`. | [Services Agreement](https://openai.com/policies/services-agreement/) |
| MiniMax | Cloud | An API key. Default model `MiniMax-M2.7`. | [Terms of Service](https://www.minimax.io/platform/protocol/terms-of-service) |
| Z.AI | Cloud | An API key. Default model `glm-5.1`. | [Terms of Use](https://docs.z.ai/legal-agreement/terms-of-use) |
| Custom | Wherever you host it | The address of any OpenAI-compatible server, and a key if it needs one. | The license of the model you serve |

Luminara does not download a language model, so the license of a local one is the license of
the model you load. [model-licenses](model-licenses/README.md#language-models) has the licenses
of the three models it prefers in LM Studio (Qwen3 14B, QwQ 32B and Llama 3.3 70B).

API keys are stored in your macOS keychain. With LM Studio or Ollama, book text stays on your Mac.
With a cloud provider, the text being analyzed is sent to that provider and billed to your account
under its terms.

## Web novels

Luminara can download web novels and turn them into audiobooks. It uses
[lightnovel-crawler](https://github.com/lncrawl/lightnovel-crawler), an open-source downloader that
supports a long list of web novel sites. It is an optional add-on:

1. Open **Novels** and choose **Install Novel Downloader**. It takes about 400 MB, is installed
   once into its own Python environment, and doesn't affect anything else. Luminara tells you
   when an update to it is available.
2. Search for a novel by title, or paste its web address, and download it. Chapters and the cover
   are saved in a **Novels** folder inside your storage folder (**Settings > Storage**).
3. Send it to **Convert**. A novel split into volumes becomes one M4B per volume; otherwise one M4B.

In **Settings > Novels** you can:

- set how many requests a second the downloader sends to a site,
- add **site logins** for sites that show some chapters only to logged-in readers, such as
  royalroad.com. Logins are kept in your macOS keychain.

Downloaded chapters can be cleaned up before conversion, removing site notices and other text
that isn't part of the story, with help from your language model if you have one set up. If the
same novel ends up in the library twice, Luminara offers to merge the copies.

Download only novels you have the right to use, and keep to each site's terms.

## Models and their licenses

Voice and language models are not part of Luminara. They are downloaded from
[Hugging Face](https://huggingface.co) when you install them, and each one has its own license.
Some allow personal use only, and some (CSM, for example) require you to accept terms on Hugging
Face and add an access token in Settings first. Check a model's license before you use its audio
for anything beyond personal listening.

[model-licenses](model-licenses/README.md) has a copy of the license of each voice model and audio
tool, read from Hugging Face on 2026-11-23:

- **Permissive** (Apache-2.0 or MIT): Kokoro, Soprano, Chatterbox, Marvis, CSM, Dia, Ming-3.0,
  Qwen3-TTS, Maya. Orpheus is Apache-2.0 too, but is built on Llama 3.2, so Meta's Llama 3.2
  Community License also applies.
- **Non-commercial**: Spark and OuteTTS (CC-BY-NC-SA-4.0; OuteTTS's Llama parts are also under the
  Llama 3.2 license), and Breeze TTS 2 (BreezeBlue Research and Non-Commercial License).
- **Fish Audio Community License**: Drama 3 and Drama 3 (4-bit). Free for research and
  non-commercial use. Commercial use only while your annual revenue is under USD 500,000, and
  never as a hosted text-to-speech service for others.

The audio tools are Apache-2.0 or MIT (Qwen3 voice copying, Whisper, Qwen3-ASR, VibeVoice-ASR,
Qwen3 Forced Aligner, MossFormer2), CC-BY-4.0 (Parakeet), and Meta's SAM License (SAM-Audio),
which is free of charge but forbids some uses. Their licenses are in the same folder, and so
are those of the extra files some voice models download (audio codecs and tokenizers). One of
them matters for CSM: it downloads Llama 3.2 tokenizer files, which are under Meta's Llama 3.2
license.

Only convert books you have the right to use. Luminara does not remove DRM.

## Privacy

Luminara does not collect analytics, and your books and audio stay on your Mac unless you choose
a cloud language model (below). It connects to the internet only to:

- download models and Python packages when you install them,
- check this repository for a new release (set it to manual in Settings to stop this),
- reach the language model you choose, if any. With LM Studio or Ollama on your Mac nothing
  leaves it. With a cloud provider, the book text being analyzed is sent to that provider under
  its terms,
- download web novels, if you use that add-on.
