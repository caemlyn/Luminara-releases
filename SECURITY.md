# Security policy

## Supported versions

Only the latest release gets fixes. Please update before reporting.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/caemlyn/Luminara-releases/security/advisories/new).
Don't open a public issue.

Include the Luminara version, your macOS version, what you found, and the steps to reproduce it.
You'll get a reply within a week. A fix ships in a new release, and the report stays private
until then.

## Scope

In scope: the Luminara app and the files in this repository's releases.

Out of scope: the third-party models, Python packages, Python and ffmpeg listed in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Report those to their own projects.
