# Contributing

Luminara's source code is not public, so this repository does not take pull requests. You can
still help:

- **Report a bug** with the [bug report form](https://github.com/caemlyn/Luminara-releases/issues/new?template=bug_report.yml).
- **Suggest a feature** with the [feature request form](https://github.com/caemlyn/Luminara-releases/issues/new?template=feature_request.yml).
- **Report a security problem** privately, as described in [SECURITY.md](SECURITY.md).

Search the existing issues first, and keep to the [code of conduct](CODE_OF_CONDUCT.md).
